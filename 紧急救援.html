空间相对运动与相遇推演

指挥车以 10m/s 向东(X)行驶。无人机相对车以 8m/s 向北(Y)巡航，高度 45m(Z)。第 5s 时自由释放物资。此时一遇难者向南移动，并在落地瞬间恰好接住物资。
📝 步骤一：绝对速度合成
物资自由释放，初始速度等于无人机绝对速度。
V_绝 = V_车 + V_相对 即 X轴分速 Vx = 10m/s，Y轴分速 Vy = 8m/s。
✈️ 步骤二：3D空间平抛落点
释放点坐标：(50, 40, 45)。下落时间 t2：
Z = ½gt² ⇒ 45 = 5t² ⇒ t2 = 3s 落地水平位移：ΔX = 10×3 = 30m, ΔY = 8×3 = 24m。
落点绝对坐标：X = 80m, Y = 64m, Z = 0m。
🏃 步骤三：相遇逆向求解
设遇难者起点为 (80, 80)，向南(-Y)移动至 (80, 64)。
总用时 T = t1 + t2 = 8s。移动距离 S = 16m。
遇难者速度：V_vic = 16 / 8 = 2 m/s
